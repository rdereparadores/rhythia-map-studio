# Changelog

## 0.1.0

Initial release of Rhythia Map Studio.

- Generate Easy, Normal and Hard maps from audio and export them to Rhythia.
- Detect repeated sections and reuse recognizable patterns with phrase-level variation.
- Optionally separate vocals, drums, bass and instruments locally and choose a musical priority.
- Preview and edit notes, regenerate regions, and undo or redo edits.
- Save portable projects with embedded audio, autosave and recovery.
- Provide a basic workflow and advanced controls with English and Spanish interfaces.
- Include modular source code, automated tests and Windows packaging tools.
